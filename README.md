# Adventure Next · Goa 2026 — Rider Registration

A responsive static website prototype for rider details, emergency contact, jersey orders, and hotel ID coordination.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **new repository** (for example, `adventure-next-goa-registration`).
2. If you want the site accessible to everyone, make the repository **Public**. Do not put real rider data, ID documents, passwords, or secrets in the repository.
3. Upload `index.html`, `README.md`, and `.nojekyll` to the **top level** of the repository (not inside another folder), then commit the changes.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a minute or two and refresh the Pages settings. GitHub will show the published URL, usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Important limitations

- This is a **front-end demo only**. The form validates and displays a local review; it does **not** send or store submissions.
- Selecting an ID file does **not** upload it anywhere.
- GitHub Pages hosts static files; it is not a secure database or form-processing backend.
- Before collecting real driving licence details, emergency contacts, or ID documents, connect a secure backend with access controls, encryption, a privacy notice, retention/deletion rules, and restricted access.
- Do not commit real personal data or uploaded identity documents to this repository. If the repository is public, anyone can view its contents.
- Confirm what ID the hotel actually requires. Prefer masked Aadhaar or another accepted ID, and never request an Aadhaar OTP.
