# Adventure Next — Goa 2026

A responsive static event website combining the two supplied ride handbooks.

## Publish with GitHub Pages
1. Create a repository (for example `adventure-next-goa-2026`).
2. Upload `index.html`, `cb500x-hero.jpg`, `README.md`, and `.nojekyll` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Open the published URL shown in Settings → Pages after deployment finishes.

## Important
- The registration form is a front-end demo only. It does not send/store details or upload ID files.
- Connect a secure backend before collecting real personal data.
- Rider phone numbers from the supplied roster are omitted from this public version.
- Source figures need confirmation: the handbook says 26 total riders, while listed group counts (6 + 7 + 3) total 16.
- QR codes are placeholders in the source and need real route/invite URLs.
- Confirm the final route, timings, hotel requirements and roster with organisers.


## Updating the site later
Edit `index.html` for text, sections, layout and form fields. Replace `cb500x-hero.jpg` to change the background motorcycle image, keeping the same filename unless you also update the image path in `index.html`. Commit the changes to the `main` branch; GitHub Pages will redeploy automatically.
